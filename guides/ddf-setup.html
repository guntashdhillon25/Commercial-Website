1Create your data feed in REALTOR Link®

This tells CREA which listings to send you. Screens change from time to time, so the button names below may differ slightly.

  1. Sign in at realtorlink.ca and open DDF® (the Data Feed icon).
  2. Click “Add a Data Feed”.A wizard walks you through the rest.
  3. Choose the feed type “National Shared Pool”.This gives you listings from every brokerage that shares them, not just yours — what you want for a lease search page. (Pick “My Listings” instead if you only want to show your own.)
  4. Set the filters so you only get commercial space for lease in your area.Property type: Commercial (and Business if offered). Transaction: For lease (it may say “For rent”). Area: your board(s), cities or postal codes. Filtering here keeps everything else simple.
  5. When asked where the data goes, choose your own website.Enter the web address where the page will live (you can use your main domain, e.g. https://yourname.com). Don't pick myRealPage here — a myRealPage feed only feeds myRealPage's own listing pages.
  6. Accept the DDF® terms and finish the wizard.
  7. Write down the feed's username and password somewhere safe.In CREA's technical docs these are called the client ID (username) and client secret (password). Never paste them into a web page, email or chat.
New feeds can take a while to start.If a later step says there are no listings, wait until CREA shows the feed as active, then try again.

2Set up your computer and a free Cloudflare account

  1. Create a free account at dash.cloudflare.com.The free plan allows 100,000 requests a day — far more than this page needs.
  2. Install Node.js (the “LTS” version) from nodejs.org.Then open a terminal (Mac: Terminal app. Windows: PowerShell) and check it worked — you should see a version number: 
    node -v
  3. Download the project code.Go to the project on GitHub, click the green Code button → Download ZIP, and unzip it. You'll use two folders: ddf-worker and prototypes.
  4. In the terminal, move into the ddf-worker folder.Type cd (with a space), drag the folder into the terminal window, and press Enter.
  5. Connect the terminal to your Cloudflare account.A browser window opens — click Allow. 
    npx wrangler login

3Put the Worker online and add your feed password

  1. Publish the Worker.When it finishes it prints your Worker's address, like https://ddf-listings.yourname.workers.dev. Copy it — you'll need it twice. 
    npx wrangler deploy
  2. Add the feed username.Run this, then paste the DDF username when asked and press Enter. Nothing shows while you paste — that's normal. 
    npx wrangler secret put DDF_CLIENT_ID
  3. Add the feed password. 
    npx wrangler secret put DDF_CLIENT_SECRET
  4. Add a private key for the setup page.Make up a long random phrase (e.g. maple-harbour-47-lantern) and paste it when asked. It stops anyone else from opening the setup view in Part 4. 
    npx wrangler secret put ADMIN_KEY

4Check the connection to CREA

  1. Open the setup view in your browser.Use your Worker address and the private key from step 3: 
    https://ddf-listings.yourname.workers.dev/explore?key=YOUR-PRIVATE-KEY
    You should see listingsInFirstPage above 0, a list of fieldNames, and two sample listings.
  2. Look at sampleAsThePageSeesIt at the bottom.Check that size, rent, address, photo and brokerage look right. If something is empty that shouldn't be, your feed may use different field names — send me the fieldNames list and I'll adjust the Worker.
  3. Open the listings address.This is what the page will read. You should see "count" and a list of listings. 
    https://ddf-listings.yourname.workers.dev/listings

5Connect the For Lease page

  1. Open prototypes/for-lease.html in a plain text editor.Mac: TextEdit (Format → Make Plain Text) or VS Code. Windows: Notepad or VS Code. Not Word.
  2. Find this line (search for DDF_ENDPOINT)… 
    const DDF_ENDPOINT = "";
    …and put your listings address between the quotes: 
    const DDF_ENDPOINT = "https://ddf-listings.yourname.workers.dev/listings";
  3. Replace the placeholders.Search the file for [Your Name], [City], [Brokerage name] and (604) 555‑0142 and put in your real details. The AGENT_PHONE line near DDF_ENDPOINT is used in error messages.
  4. Save, then double-click the file to open it in your browser.Real listings should appear with photos and a real map. The grey “Prototype” bar disappears in live mode.

6Put the page on your website

Pick one of these. Both keep myRealPage as your main site.

Recommended

A. Host it on Cloudflare Pages

Free, and you already have the account. The page lives at an address like lease.yourname.com, and you add a “For Lease” link to it in your myRealPage menu.

Only if allowed

B. Embed it inside myRealPage

Only possible if myRealPage lets you add custom HTML and JavaScript to a page. The prototype is a full page with its own header, so ask me for a “listings-only” version to paste in.

  1. (Option A) Make a new folder called lease-site, copy for-lease.html into it, and rename the copy to index.html.
  2. (Option A) Upload it.In the Cloudflare dashboard: Workers & Pages → Create → Pages → Upload assets. Name the project, drag in the lease-site folder, and deploy. Or from the terminal: 
    npx wrangler pages deploy lease-site
  3. (Option A) Add your own address.In the Pages project: Custom domains → add lease.yourname.com and follow the instructions to add the DNS record where your domain is registered.
  4. Lock the Worker to your site.In ddf-worker/wrangler.toml, change ALLOWED_ORIGINS = "*" to your page's address, then publish again: 
    ALLOWED_ORIGINS = "https://lease.yourname.com"
    npx wrangler deploy
    After this, opening the file from your computer will no longer load listings — that's expected.
  5. In myRealPage, add a menu link to the new page.

7Check CREA's display rules before going live

Showing DDF® listings means following CREA's DDF® Policy and Rules. Read them once. The page already covers most of it:

  1. Swap in the official “Powered by REALTOR.ca” logo.The page has a text placeholder that already links to REALTOR.ca. Download the official logo from CREA and replace it.
  2. Confirm the listing brokerage shows on every listing.The page shows “Listed by …” on each card and in each listing's details.
  3. Check the fields against CREA's Listing Field Display Table.The page shows size, rent, address, area, zoning, lease term, description, photos, MLS® number and brokerage. Remove any the table doesn't allow.
  4. Review the card titles.The feed has no headline, so the page builds one from the type and city (e.g. “Retail for lease in Vancouver”). Confirm your board is comfortable with that.
  5. Keep the trademark notice in the footer.Already included. Listings refresh at least every hour, and removed listings drop off automatically.

Changes don't show upThe Worker reuses results for up to an hourWait, or run npx wrangler deploy again to reset it.
Good to know
  • The listings load after the page opens, so search engines mainly index the page's written content (guide, resources, FAQ) — not each listing. myRealPage's own listing pages cover listing-by-listing search results.
  • The map uses free OpenStreetMap tiles, which are fine for a small site. If traffic grows, switch to a map provider with a free plan (I can do that).
  • If you ever share your screen or send files, make sure the DDF password isn't visible. If it leaks, change it in REALTOR Link and repeat Part 3.
